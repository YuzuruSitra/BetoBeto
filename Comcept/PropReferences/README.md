## 外注モデルに必要な指定

画像は美術と構造の基準です。以下は納品後の大きな作り直しを避けるための制作条件です。

- 基本は1マス単位で置く。床面を高さ0、上方向をYとし、配置物の原点は占有マスの中心に置く。全画像は見やすさのため個別に拡大されており、画像間の表示サイズは実寸比ではない。
- **スコーン**：平面の3頂点は、1マス基準で `(-0.46, 0.46)、(0.46, 0.46)、(-0.46, -0.46)` を目安とする。高さ約0.28〜0.33の一定厚の柱状。上面を斜めにした坂ではない。斜辺の接触面はまっすぐに保ち、アイシングや焼き目で大きく膨らませない。直角・斜辺の角度はモデル制作時に数値で固定する。
- **シュレッダー2種**：外枠を低く面取りし、刃の外周を高い囲いの下に沈めない。横から滑ってきたフルーツと刃の高さが重なること。刃と中心軸は別オブジェクトにし、刃の回転中心を一致させる。移動版の車輪は底面まで届き、車体と干渉せず回転する構造にする。
- **パイプ**：上の管と下の排出口を内部で接続し、途中に床・蓋・塞ぎ板を作らない。排出口の幅・高さと管の内径は、通すフルーツの最大寸法に余裕を加えて決める。扉は透明な別パーツで、上部ヒンジから外側だけへ開く。入口に見せないため、背面・左右は閉じ、前面だけを排出方向にする。
- **チョコフォンデュ**：皿の縁と取っ手を低くする。フルーツが踏めるチョコ液面を中央の噴出口で塞がない。皿・液面・流れるチョコを分けて扱えるようにする。
- **氷壁**：水面と氷は別オブジェクト。同じ占有位置で状態を切り替える。側面に敵が抜ける隙間を作らず、ひびを表面表現として追加できる構成にする。
- **破壊・揺れ**：クッキーとスコーンはひび表現を独立させ、本体を非表示にできるようにする。ゼリーは皿を変形させず本体だけ揺らせる構成にする。
- **床・液体**：水たまりとよだれは薄い別メッシュ。タイル上でちらつかない微小な高さだけを付け、通行するフルーツを持ち上げない。水・氷・よだれ・ガラスは材質を分けておく。
