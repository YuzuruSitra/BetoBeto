# キャラクター清書画像

黒背景・正方形の PNG、計12枚。内蔵 image_gen で生成。

フルーツは最新の添付ラフに合わせ、眉毛と手足を付けず、果皮・眼球・口に立体感のある3DCG表現で統一しています。通常顔と驚き顔は同じ造形を基準にしています。

| ブルーベリー | [通常](blueberry_normal.png) / [驚き](blueberry_scared.png) |
| オレンジ | [通常](orange_normal.png) / [驚き](orange_scared.png) |
| メロン | [通常](melon_normal.png) / [驚き](melon_scared.png) |
| 汎用手足・球体素体 | [手足](fruit_limbs.png) |

おばけは赤チェックのエプロンを着用し、足のない連続したシルエットです。側面は頭部と胴体の厚みを調整しています。
メロンは上まぶたと口ひげでボスらしさを表現し、眉毛は設けていません。

生成に使用した最終プロンプトは [generation-prompts.json](generation-prompts.json) に記録しています。
