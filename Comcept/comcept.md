# BetoBeto — おばけのスイーツキッチン

更新日：2026-09-05

### **世界観・ビジュアル**

クッキーやお菓子でできたステージで、逃げ惑うフルーツたちを集めてスイーツを完成させるゲーム。プレイヤーキャラはエプロンをしたゴースト。

**「よだれで滑らせたフルーツを、お菓子のギミックでつないでシュレッダーにぶち込む」ことがメインプレイ。** 驚かして最初の向きをそろえ、ひと滑りを起点に、反転・転向・破壊・減速が連動するピタゴラ的な仕掛けを楽しむ。ほかのフルーツを巻き込む連鎖と、跳ね返り・破砕・収穫の爽快感を重視する。

* **敵キャラ**：フルーツ（イチゴ／ブルーベリー／オレンジ／メロン等）。顔と向きの目印で進行方向が分かる。
* **床**：キッチンの青いタイル。
* **壁（障害物）**：壊れないビスケットのブロック。敵はこれを避けて進む。壊せるクッキーは丸形・チョコチップ入りで区別する。
* **ギミック**：紫のゼリー、ひび割れる丸いクッキー、車輪付きの移動シュレッダー、白い斜面を持つ三角スコーン、雪の結晶が描かれたフリーザー。
* **UI**：逃げたフルーツの数、必要なフルーツごとの収穫数、スイーツの完成度、得点、操作とチャージ状態を表示する。
* **視点**：見下ろし型。
* **主要ビルドターゲット**：WebGL。HTTPサーバー経由で起動・配信する。

### **プレイヤー（PL）の仕様**

壁やお菓子の障害物を**すり抜けて移動可能**なゴースト。敵の経路に先回りし、驚かす位置とよだれを置く位置を組み合わせて誘導する。ギミックはステージの配置物で、PLが生成するものではない。

PLには上下左右の向きがあり、顔と向きの目印で確認できる。移動方向に向きを変え、その場で向きだけを調整することもできる。

#### **ゲームパッド操作**

| 操作 | 動作 |
| --- | --- |
| 左スティック／十字キー | 移動 |
| 右スティック | その場で向きの調整 |
| 右側4ボタンの下（Xbox A／PlayStation ×） | 足元によだれを置く。メニューでは決定 |
| 右側4ボタンの左（Xbox X／PlayStation □） | 驚かす。長押しでチャージし、離すと発動 |
| 右側4ボタンの右（Xbox B／PlayStation ○） | メニューで戻る |
| MENU／START | 一時停止・音量設定 |

Web版は最初に画面をクリックして開始し、以降はゲームパッドで操作する。パッド未接続時は進行を待ち、プレイ中に切断された場合は一時停止する。

#### **アクション1：驚かす**

声を出してフルーツをびっくりさせ、**敵の進む向きを変える**。単押しと長押しで、対象と逃げる向きが異なる。

* **単押し**：0.25秒未満で離すと、**PL自身のマスと前方1マス**の敵に効果がある。対象の敵は**PLが向いている方向**へ進む。PLと重なっている敵にも効く。
* **長押し**：0.25秒以上ためると周囲に効果が広がり、敵は**PLから離れる方向**へ進む。チャージに応じて半径1〜6マスへ段階的に拡大し、**1.5秒で最大半径6マス**になる。
* 効果はボタンを離したときに発動する。最大チャージは離すまで保持でき、チャージ中も移動・向き調整・よだれ設置が可能。
* 長押しの範囲はPLのいるマスを中心とする円形で、敵がいるマスの中心で判定する。壁越しにも届く。長押しでの逃げる向きはPLの実際の立ち位置から決める。
* 驚いた敵は約1.5秒間逃走状態になり、最初は指定された方向へ歩く。逃走中も壁やシュレッダーに進路をふさがれたら、通常歩行と同じ右・左の交互転向を使う。安全な道がなければ待機する。
* **刃の直前で驚かす**：発動時に、敵の逃げる方向の隣接1マスがシュレッダーなら、回避せず勢いよく飛び込む。単押し・長押しとも、ここではよだれなしでも収穫できる。2マス以上離れている場合や横・後ろに刃がある場合は、この突入を起こさない。メロンの耐久と無敵時間は維持する。
* すでに滑っている敵を驚かせると滑走方向が変わり、連鎖数は維持される。
* **クールダウンなし**。単押しの連続使用や、発動直後の再チャージができる。一時停止・パッド切断時はチャージを取り消す。
* 自分と前方の枠・周囲の範囲円・ゲージで効果範囲とチャージ量を示す。発動時は波紋と効果音、敵の「！」と驚く動きで反応を伝える。

#### **アクション2：よだれ**

おいしいスイーツを想像して、**自分の足元のマス**によだれを垂らす。

* よだれは床の配置物となり、初期設定では**10秒間**残る。壁・ゼリー・壊れていないスコーンやクッキー・パイプ・シュレッダーには置けない。フリーザーの上や、お菓子が壊れて開いたマス、外周の床には置ける。
* **クールダウンは0.3秒**。敵の進路に先回りして、短い間隔で置ける。
* よだれに触れたフルーツは、そのときの進行方向へ滑り始める。ほかのフルーツに当たると巻き込み、同じ連鎖で滑るフルーツの基準速度が連鎖数に応じて上がる。
* 滑った勢いで固定・移動シュレッダーに入ると収穫になる。ビスケットの壁に激突した場合は潰れて跳ね返り、短く硬直する。壁への激突だけでは収穫されない。
* ゼリーやスコーンで跳ね返っても、クッキーやスコーンを壊して通り抜けても、フリーザーで減速しても、**滑走状態と連鎖数を保つ**。ギミックに当たるだけでは連鎖数は増えず、ほかのフルーツを巻き込むと増える。
* 軌跡・飛沫・衝撃波・壁やカメラの揺れ・短いヒットストップ・連鎖音で爽快感を出す。収穫得点は1体につき100点×連鎖数。

#### **PLの立ち回りイメージ**

1. フルーツの進行方向、お菓子の配置、シュレッダーの位置と往復のタイミングを読む。
2. 単押しでは敵を自分のマスか前方1マスに入れ、逃がしたい方向に向いて驚かす。
3. 周囲をまとめて動かすなら、逃がしたい方向の反対側に立ち、チャージして驚かす。
4. 逃げる先に足元のよだれを置き、ギミックへ滑らせる。
5. ゼリーで反転 → クッキーを割って通路を開通 → スコーンで曲げる → フリーザーでタイミングをずらす → 別のスコーンで刃へ送る、といった連動を狙う。
6. ほかのフルーツも巻き込み、動く刃へ到着する瞬間を合わせて連鎖収穫する。

刃の1マス前まで来た敵には、その刃の方向へ驚かすことで直接飛び込ませることもできる。

### **お菓子のギミック**

| ギミック | フルーツへの作用 | 初期設定・見せ方 |
| --- | --- | --- |
| **ゼリー** | 滑ったフルーツを、来た方向へ180度跳ね返す。滑走と連鎖は続く | ぷるんと揺れ、紫の飛沫・波紋・弾む音で反応する |
| **クッキー** | 滑ったフルーツが当たるたびにひびが増える。壊れるまではフルーツを止め、最後の衝突では破壊してそのまま通り抜ける | **3回**で破壊。破壊後は**20秒間**復活せず、その後に耐久を全回復して戻る |
| **移動シュレッダー** | 横または縦の直線上を往復する。滑ったフルーツが接触すると収穫する | **1マス/秒**。壁・お菓子・ほかの刃などで反転。車輪と往復矢印で移動軸を示す |
| **スコーン** | 直角三角形。歩行・滑走ともマスに乗ってから、白い斜面で**90度**、裏の直角の辺で180度転向する。**20回目**の滑走衝突で壊れ、その一撃は直進して通り抜ける | 向きは4種類。歩行で踏んでも耐久は減らない。破壊後は一時的に床になり、**5秒後**に耐久20回まで全回復して戻る |
| **フリーザー** | 踏んだフルーツはしばらく凍り、歩行・逃走・滑走が遅くなる。滑走そのものは止めない | **3秒間、速度0.35倍**。薄い氷の殻と冷気の飛沫で凍結を示す |

* 通常歩行中のフルーツはゼリー・壊れていないクッキーを避ける。例外として、オレンジは歩行中にもクッキーへ体当たりし、1ダメージを与える。壊せなければ右・左の交互転向を行い、壊せたらそのまま直進する。スコーン・フリーザーと、壊れたお菓子のマスは歩行中にも通れる。
* スコーンは歩行中の壁として扱わず、フルーツが上に乗ってマスの中心へ到達してから、スコーンの向きに従って転向する。壁で曲がる左右の順番は進めない。歩行での乗り上げは小さな跳ねと音で示し、滑走時の衝撃とは区別する。
* クッキー・スコーンの復帰先にフルーツや移動シュレッダーがいる場合は、空くまで復帰を待つ。復帰時はそのマスのよだれを消す。ゴーストは復帰したお菓子もすり抜けられる。
* 移動シュレッダーは盤外・パイプにも進入しない。歩行中のフルーツがいる進路は反転し、通常歩行側も刃が移動中のマスを避ける。**動く刃が通常歩行のフルーツを自動で収穫することはない。** 両方向がふさがっている間は待機する。
* 再びフリーザーを踏むと凍結時間を更新する。速度倍率は重複せず、解凍すると元の速度に戻る。メロンにも凍結が有効で、シュレッダーへの耐久2回は維持する。
* クッキー・スコーンの復帰、刃の移動、凍結時間はゲーム内時間で進む。一時停止・ヒットストップ中は進まない。
* クッキーの耐久、クッキー・スコーンそれぞれの復帰時間、刃の移動速度、凍結時間と速度倍率は、ステージごとに調整できる。復帰時間の初期値はクッキー20秒・スコーン5秒。

#### **連鎖の継続と停止**

* 壊れない壁への激突や、クッキーを壊しきれなかった衝突では、**当たったフルーツだけ滑走が止まり、そのフルーツの連鎖は終了する**。すでに巻き込んだほかのフルーツは、それまでの連鎖数を保って滑り続ける。クッキーを先にひび割れさせ、最後の一撃から先の経路をつなぐ段取りも狙える。
* 衝突後の硬直中は後続の接触やよだれで滑走を再開しない。同じ連鎖には同じフルーツを再び巻き込まず、壁際の玉突きで衝突とヒットストップが繰り返されるのを防ぐ。
* フリーザーの減速は**凍ったフルーツだけ**にかかる。同じ連鎖のほかのフルーツまで遅くなることはない。凍結中も連鎖数に応じた基準速度は更新され、解凍後はその時点の連鎖数に応じた速度へ戻る。
* フリーザー上でほかのフルーツに巻き込まれ、滑り始めた場合にも凍結する。よだれから直接滑り込ませる場合と同じように、連鎖の途中で到着タイミングをずらせる。

### **敵（フルーツ）の仕様**

* フルーツはステージ上側の食品用ガラス管をイメージしたパイプから落ちてくる。透明な管、銀色の留め具、白いパッキンと外向きに開く逆流防止フラップを備える。
* パイプは**供給専用の一方通行**。出現したフルーツは盤面側（下方向）にのみ出られ、盤面からパイプへは歩行・滑走とも再進入できない。出現直後に驚かされても逆走せず、パイプ経由で盤外へ逃げることはない。
* 歩行では**壁や障害物で進路をふさがれるまで直進**し、曲がり角や交差点だけでは向きを変えない。障害物に当たると、進行方向を基準に**右→左→右→左と90度ずつ交互に曲がる**。全フルーツが右折から始める。
* 曲がる予定の側がふさがっていれば反対側へ曲がり、次は実際に曲がった側の反対を優先する。両側ともふさがっている袋小路では後退し、すべてふさがっていれば待機する。
* 左右の順番はフルーツごとに保持する。驚かす・滑走・ギミックによる方向転換や、袋小路での後退では順番を進めない。逃走中に障害物へ当たった場合も、同じ交互転向を使う。
  * **イチゴ**：標準速度で直進する。
  * **ブルーベリー**：速く直進する。
  * **オレンジ**：ゆっくり直進する。歩行中にクッキーへ当たると、**1回の接触で1ダメージ**を与える。壊せなければ短く跳ね返った後、ほかのフルーツと同じ交互転向を行う。**その衝突で壊せたら直進して通り抜け、次に曲がる左右の順番も維持する。** 滑走中も破壊後は通り抜ける。
  * **メロン**：標準速度のボス枠。最初のシュレッダー衝突には耐えて跳ね返る。短い無敵時間の後、よだれで滑らせるか刃の直前で驚かせて、もう一度当てると収穫できる。
* **通常歩行中はシュレッダーを避け、自分から突っ込まない。よだれで滑らせて刃に突っ込ませるのが基本の収穫方法。例外として、刃の隣でその方向へ驚かされた敵は、よだれなしでも飛び込む。**
* **上下左右いずれも、盤面の境界を越えた瞬間に「脱出」**としてカウントする。外周の床に乗っただけでは脱出しない。

### **勝敗条件**

* **ゲームオーバー**：一定数のフルーツに逃げられる。
* **勝利**：目的のスイーツに必要なフルーツを、種類ごとの必要数まで収穫する。別の種類の余剰分では代用できない。

### **盤面仕様**

* 同梱ステージは**16×9と20×12**。広げずに通路の余白を取り、ギミックの連動を読める配置にする。配置ツールでは幅16〜32・高さ9〜18に対応する。
* 敵生成パイプ：2〜3基を目安に配置する。
* 出口オブジェクトは置かない。外周を床で開けると、その先の盤外が自動で出口になる。既存データの出口記号 `E` は床として読み込む。
* シュレッダー：固定型と移動型を合わせて4〜8か所を目安に配置する。
* 「はじめてのキッチン」は中央のゼリーと周囲のスコーンで方向を変え、クッキーを割って固定刃や下段の横移動する刃へ送るステージ。フリーザーは2番目のステージで使用する。
* 「ひろびろベリー工房」は2つの斜面をつなぐ経路と、縦・横の移動シュレッダーを備える。壊れるクッキーを経路の途中に置き、通路を開く手順と到着タイミングを考える。

### **アウトゲーム・制作ツール**

* **シーン構成**：タイトル → ステージセレクト → ゲーム本編 → リザルト。アウトゲームは本編と別シーンにし、開始時はステージセレクトを経由する。リザルトからは再挑戦またはステージ選択へ戻れる。
* **メニュー・オプション**：あそびかた、一時停止、BGMと効果音それぞれの音量調整。メニューもパッドで操作でき、音量設定は保存する。
* **開発分担**：複数人で開発できるよう、進行・入力・敵・盤面・UI・音・演出・エディタをフォルダごとに分ける。
* **Prefab**：今後モデルをブラッシュアップできるよう、キャラクター・敵・壁・床・罠・パイプ・よだれと5種類のギミックは差し替え可能なPrefabにする。
* **独立ステージエディタ**：Unityとは独立した、1レベルを設計できるグリッドペイント式の配置ツール。
  * 拡大縮小、パン、Undo／Redoなど、配置を快適に行えるUIを用意する。
  * ステージ名、サイズ、必要フルーツ数、脱出上限、出現間隔、よだれの寿命と、ギミックの耐久・時間・速度を編集できる。
  * ゼリー・壊れるクッキー・横/縦の移動シュレッダー・スコーン・フリーザーをペイント配置できる。スコーンはRキーまたは回転ボタンで90度ずつ向きを変える。
  * 扱うのはレベルの配置とルール。壁などのモデルデザインはここでは選ばない。
  * JSONの読み込み・書き出しと検証に対応する。
* **Unityへの取り込み**：JSONからPrefabを配置したシーンを生成し、Unity上で見た目や配置を調整できるようにする。生成したステージはステージセレクトから選べる。既存ステージは更新先のシーンを選び、JSONから床・配置物・ルールを再生成して上書き保存できる。カメラや照明、配置用グループ外のオブジェクトとシーンの参照を維持し、ステージ名・選択画面のプレビューも更新する。登録済みステージは重複追加しない。

同梱の画像はキャラクター・アート・よだれによる撃退のラフ資料として使用する。UIはラフ画像に準拠させず、操作と状況の読み取りやすさを優先する。
