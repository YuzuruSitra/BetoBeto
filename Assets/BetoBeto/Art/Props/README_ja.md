# BETOBETO 小物モデル

納品物をBlender 5.2で加工した14種類の小物です。既存のステージPrefabに反映済みです。

[モデル一覧](Documentation/Props_Overview.png) / [ゼリーのボーン変形プレビュー](Documentation/Jelly_Bones.gif)

- 編集用blend：`G:\Blender\CleanAssets\BETOBETO\Props`
- 元の納品ZIP：`G:\Blender\Assets\BETOBETO_Pack\Props`（変更していません）
- `Models`：Unity用FBX。ゼリーには変形用リグを含みます。コライダーは含めず、ゲームの既存のマス判定を使います。
- `Textures`：ベースカラー、法線、Metallic/Smoothnessパック。Unityでは最大1024px・ミップマップ付きです。
- `Materials`：不透明物はURP Lit、透過物は `BetoBeto/Prop Transparent Fresnel`。ガラス、水、氷、よだれ、ゼリーに視線角度によるフレネル発光を加え、輪郭を見分けやすくしています。各材質の `Glow strength`・`Glow falloff` で強さと幅を調整できます。
- `Prefabs`：単体の美術アセット。`Prefabs/Confetti`には個別に飛ばせる果肉パーツがあります。
- `Documentation`：ZIPとの対応・メッシュ情報・使用材質、およびモデルの一覧画像。

## 編集と破壊表現

各blendの `SOURCE - unmodified delivery` コレクションには加工前メッシュを非表示で残しています。テクスチャはblendにパック済みで、黒背景の撮影用カメラ・照明も保存しています。

**クッキーは22片、スコーンは26片の立体ボロノイ破砕**です。破片は断面を塞ぎ、断面用の生地材質を割り当てています。外側には納品のUV・テクスチャを保持しています。破片ごとに `Shard_XX` 頂点グループがあり、後から個別の形状調整もできます。

| シェイプキー | 用途 |
| --- | --- |
| Basis | 継ぎ目を閉じた通常形状 |
| Crack | 破片間の隙間を広げる。Blenderで0〜1、Unityで0〜100 |
| Break | 破片を外側・上方へ散らし、小さくする |

ゲーム側の `PropDamageVisual` が耐久値からひびの量を決め、最後のヒットで約0.38秒の破砕表示後に非表示にします。ゲーム判定上の破壊はヒット時点で成立し、演出が進路を塞ぎません。復活時にはキーと表示をリセットします。クッキー3回・20秒、スコーン20回・5秒という既存の設定を使用し、ステージごとの設定を上書きしません。

## 形状と可動部分

- スコーンは平面の直角二等辺三角形に補正。白い斜辺が反射面で、他の2面は壁です。坂道にはしていません。
- シュレッダーは納品の外装を保持し、一体化していた刃を独立した8歯ローターに変更。中心は平らに保ち、歯先だけ最大0.024マスの浅い起伏と0.004マスの面取りを付けています。メタルネス1.0の照明に、視線方向で歪む平面投影の反射帯を組み合わせます。反射帯は刃と一緒には回りません。移動版の車輪は前後2列の計4個で、進行距離に応じて回転します。
- パイプは不透明な筒・塞がれた出口を、中空のガラス管と独立した上ヒンジの扉に変更。扉は外側へだけ開きます。隣同士のパイプが重ならないよう、留め具を含む幅を約0.96マス・高さを約2.18に抑えています。配置・論理占有の中心は従来どおり1マスです。
- ゼリーは皿とスキニングされた本体を分離。固定用 `JellyRoot` と変形用 `JellyLower / JellyMiddle / JellyTop` の4本のボーンがあり、皿を動かさず本体を曲げたり伸縮できます。Unityの `JellyBoneWobble` が通常時の小さな揺れと、衝突方向に応じた減衰する揺れを生成します。blendには編集用の `Jelly_Idle`・`Jelly_Hit` アクションも入っています。
- チョコフォンデュは中央の流れを分離し、踏み越えられる低さを維持しています。
- 氷と水は同じ位置で切り替えます。氷表面のひびは被弾時に表示し、既存の寿命・連続衝突による破壊遅延を使います。
- 水・よだれは床上の薄いメッシュです。天板は平らなスラブで、盤外の出口を塞ぐ縁を持ちません。
- 氷の重複納品は1点にまとめています。ZIP名の「cheese wedge」はスコーン、「blue pool float」は水たまりです。

## 色と光沢の調整

- ゼリー本体は明るい紫で幅0.98マス、皿は幅1.04マス。本体の外周から縁がわずかに出る比率とし、皿が1マスを少し超えることを許容しています。皿の厚み・高さ、本体・ボーン・判定はそのままです。[皿の更新プレビュー](Documentation/Jelly_Plate.png)。衝突時に潰れてから弾み戻るボーン変形を加えています。フルーツ側にも約0.34秒の伸縮と小さな跳ねを表示します。判定位置は動かしません。
- シュレッダー外装は明るいピンクの非金属塗装、刃は独立した磨き金属材質です。HDR環境の映り込み、直接光のハイライト、刃先のきらめきを組み合わせています。
- 床のよだれは淡い青白色・基本不透明度0.13。フレネル輪郭と点滅する小さな光で位置を示します。口から落ちるしずくの材質・演出は変更していません。
- `Art/Environment/KitchenReflection.exr` は窓と観葉植物のあるキッチンの反射専用HDR画像です。Unityでは256px/面の事前にぼかしたキューブマップとして使います。ステージの照明・テーブル・背景小物は `KitchenEnvironment.unity` にまとめ、各ステージから追加読み込みします。Directional Lightには葉影のCookieを設定しています。詳細は同フォルダのREADMEを参照してください。

## Unityで再適用する場合

`BetoBeto > Apply Delivered Prop Models` を実行します。ステージPrefabのGUIDを保持して見た目を置き換え、GameAssetsに天板・果肉パーツを設定します。既存5ステージの天板も更新済みです。キャラクター、ステージの配置、耐久・移動・衝突ルールには変更を加えません。

再加工のスクリプトは `Tools/Blender/prepare_props.py`、テクスチャのパックは `pack_prop_maps.py`。加工スクリプトは作業フォルダ `G:\Blender\AssetWork\BETOBETO_Props` の展開済み納品データを入力にします。編集済みblendを手作業で変更した後は、再生成で上書きせず、選択した加工済みメッシュだけをFBXへ書き出してください。非表示のSOURCEコレクションと撮影用のカメラ・照明はUnityへ書き出しません。

確認はメッシュ・材質・インポート・コンパイル、およびBlender/Unityの静止画で行っています。ゲームの動作テストや自動テストは実施していません。
