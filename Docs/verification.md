# プロトタイプの確認記録

2026-09-05 / Windows / Unity 6000.6.0f1 / UnityCLI + Unity Pipeline

## ゲームの確認範囲

ゲームパッド対応後の結果はEditMode 14/14件成功、PlayMode 23/23件成功です。今回のPlayModeの生データは `Logs/QA/Gamepad-PlayMode-results.xml` と `Logs/QA/Gamepad-PlayMode-status.json` に保存しています。

- EditMode：JSON検証、座標変換、レシピの勝敗条件、脱出上限、フルーツの進行ルール、Prefab参照。
- PlayMode：タイトル→ステージ選択→2番目のステージ→勝利リザルト→再挑戦、敗北リザルト→ステージ選択。各画面が別シーンで、音声オブジェクトが重複しないこと。
- 氷の配置制限・寿命・ポーズ中の停止、よだれを直接踏ませた滑走開始、3体の巻き込み・共有加速・900点の収穫、壁での停止と反動、メロンの耐久と無敵時間。
- 4種類とも通常移動中はシュレッダーを避けること。壁と刃に囲まれると待機し、よだれを置いた場合にだけ刃に突入すること。
- 両サンプルステージで4種類それぞれの移動を60秒分進め、よだれなしでは収穫数が増えないこと。
- 仮想ゲームパッドからの実入力で、ゴーストがクッキー壁を通過できること。テスト中だけ入力のフォーカス条件を固定し、終了時に戻す。
- 右スティックで位置を変えずに向きが変わり、スティックの小さな揺れで向きが変わらないこと。下ボタンで足元によだれ、左ボタンで向いている前方1マスに氷が出ること。前方が壁なら別のマスに置かれず、待ち時間も発生しないこと。
- フルーツの顔が通常移動と滑走方向に一致すること。
- パッド入力だけでタイトル→選択→2番目のステージ→音量変更→復帰→リザルト→再挑戦→選択→タイトルと遷移できること。決定／復帰の入力が本編のよだれ設置に漏れないこと。
- デバイスを無効化すると一時停止し、再接続後も復帰操作まで停止を保つこと。実機パッドが接続されている場合も検証できるよう、テスト実行中だけ既存パッドのUnity入力を無効化し、終了時に元の状態へ戻します。

## 画面確認

Unity Game Viewを1920×1080でキャプチャして、タイトル、ステージ選択、ゲーム画面、一時停止・音量設定、リザルトを確認しました。連鎖と壁の演出は、通常のステージ内にフルーツを配置した確認用の場面を使っています。タイトルから選択を経由する本番の起動経路はPlayModeテストで別途確認しています。

同じシュレッダーで3体を連続収穫した際、HUDの得点が900、収穫数が3、盤面の得点表示が「+900」になることを確認しました。演出を含む実行中、Consoleのエラーは0件でした。

画像とテストの生データは `Logs/QA/` に保存しています。このフォルダは既存の `.gitignore` によりGit管理対象外です。

## Windowsビルド（ゲームパッド対応前の記録）

`Builds/Windows/BetoBeto.exe` のStandaloneWindows64ビルドに成功しました。出力合計は約118 MB、エラー0件です。ビルドレポートは `Logs/QA/Windows-build-report.json` に保存しています。

最終ビルドの警告1件は、配布用PlayerにRuntimePipelineConfigがないためUnity Pipelineの実行時サーバーが無効になるという通知です。Unity EditorからのUnityCLI操作は利用できます。

生成した実行ファイルをウィンドウなしで5秒間起動し、起動中の例外・エラーログがないことを確認して終了しました（`Logs/QA/Windows-startup.log`）。描画と操作の確認はUnity Editorで行っています。

保存・ビルドに伴い、既存のURPと描画設定もUnity 6000.6のシリアライズ形式へ更新されています。

## WebGLとゲームパッド対応

主要ターゲットをWebGLに切り替えました。出力は `Builds/WebGL`、再ビルドは `BetoBeto → Build → WebGL`、ローカル起動は `python Tools/serve_webgl.py` です。Web向けの初期メモリ128MB・最大1024MB、Gzipと展開フォールバック、日本語フォント、クリックによる音声開始画面を設定しています。

ブラウザでタイトル→ステージ選択→キッチン→一時停止画面を確認しました。Web版のパッド未接続時は、開始前で進行が止まり、接続案内が表示されます。日本語の説明と音量スライダーに重なりはありません。画面拡大時の文字のぼやけを防ぐため、Canvasの倍率が変わると文字メッシュを再生成します。

パッドの移動、方向転換、よだれ／氷の配置、メニュー操作はUnityの仮想Gamepadを使う自動テストで確認しています。ブラウザ内の実機パッドでの操作と、実際の音の聴感確認は未実施です。

最終WebGLビルドは成功（15,903,170 bytes、エラー0件、警告3件）。ログは `Logs/QA/WebGL-build-report.json` に保存しています。385×800で起動してから1280×800へ拡大し、タイトルの日本語とボタンの文字が鮮明に描き直されることを再確認しました。確認後にブラウザのサイズ指定を解除しています。

ビルド時にはUnity PipelineのPlayerサーバー無効化と、URPのデバッグ用Occlusionシェーダーの除外に関する警告がありました。ブラウザではFSR補間シェーダーの未対応／除外について警告1件が出ていますが、実行時エラーはありませんでした。現在のゲームはポストプロセス効果を使用していません。WebGLビルドに伴うMobile描画アセットのシリアライズ更新も含まれます。

Webの入力仕様は[Unity公式マニュアル](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-input.html)、音声開始の制約は[Web Audioの公式説明](https://docs.unity3d.com/6000.0/Documentation/Manual/webgl-audio.html)に沿っています。
