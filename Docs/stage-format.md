# ステージJSON v1

座標は左上が `(0,0)`。Xは右方向、Yは下方向に増えます。Unityの座標ではXZ平面を使い、上の行ほどZが大きくなります。

```json
{
  "version": 1,
  "name": "はじめてのキッチン",
  "dessert": "フルーツタルト",
  "width": 16,
  "height": 9,
  "rows": ["各行に幅と同じ個数のASCII記号を記述"],
  "recipe": {"strawberry": 5, "blueberry": 4, "orange": 3, "melon": 1},
  "escapeLimit": 10,
  "spawnInterval": 3.6,
  "iceLifetime": 5,
  "droolLifetime": 10,
  "cookieHits": 3,
  "cookieRespawnSeconds": 20,
  "sconeRespawnSeconds": 5,
  "movingShredderSpeed": 1,
  "freezerSeconds": 3,
  "frozenSpeedMultiplier": 0.35
}
```

上記のrowsは説明用です。読み込み可能な完全な例は `Assets/BetoBeto/Stages/kitchen-01.json` と `kitchen-02.json` にあります。

| 記号 | 内容 | 制約 |
| --- | --- | --- |
| `.` | 床 | 制約なし |
| `#` | 壊れないビスケットの壁 | プレイヤーは通過できる |
| `P` | 生成パイプ | 最上段、2〜3基。下へ供給する一方通行。盤面から再進入不可 |
| `X` | 固定シュレッダー | `H`・`V`と合わせて4〜8箇所 |
| `E` | 旧形式の出口記号 | 互換読み込み専用。床 `.` に変換する。新規配置は不要 |
| `G` | プレイヤー開始位置 | 必ず1箇所。ゲーム上は床 |
| `J` | ゼリー | 滑走を180度反転 |
| `C` | 壊れるクッキー | 滑走衝突、または歩行中のオレンジの体当たりで削れ、時間で復帰 |
| `H` | 横移動シュレッダー | 初期方向は右。障害物で反転 |
| `V` | 縦移動シュレッダー | 初期方向は下。障害物で反転 |
| `1` | スコーン・左上が直角 | 斜面は右下向き。上向き進入→右、左向き進入→下 |
| `2` | スコーン・右上が直角 | 斜面は左下向き。右向き進入→下、上向き進入→左 |
| `3` | スコーン・右下が直角 | 斜面は左上向き。下向き進入→左、右向き進入→上 |
| `4` | スコーン・左下が直角 | 斜面は右上向き。左向き進入→上、下向き進入→右 |
| `F` | フリーザー | 通過可能。歩行・滑走とも一定時間減速 |

幅16〜32・高さ9〜18、各行の長さはwidth、行数はheightと一致させます。各フルーツ数は0以上の整数で、合計1〜200。脱出上限は1〜99。出現間隔0.5〜30秒、よだれ1〜60秒。

出口はオブジェクトとして配置しません。上下左右の外周を床で開けると、その先の盤外が出口になります。フルーツが盤面の境界を越えた瞬間に脱出を数え、外周マスに入っただけでは脱出しません。既存シーンの出口オブジェクトもゲーム中は非表示にして床扱いにします。

パイプは出口にはなりません。出現したフルーツは下方向へ送り出し、歩行・滑走とも盤面から管への再進入を防ぎます。パイプの下側に通路を確保してください。

`iceLifetime` は旧JSONとの互換性のため残しています（従来の検証範囲は1〜30秒）。氷生成は「驚かす」に置き換わり、この値はゲーム中には使用しません。ステージエディタでも編集項目から外しています。驚かす範囲・チャージ時間は全ステージ共通で `Player/ScareRules.cs` に定義しています。

追加パラメーターは省略可能です。旧v1 JSONを読み込むと、以下の既定値を使います。

| フィールド | 既定値 | 設定範囲 |
| --- | --- | --- |
| `cookieHits` | 3回 | 整数1〜10 |
| `cookieRespawnSeconds` | 20秒 | 1〜30秒 |
| `sconeRespawnSeconds` | 5秒 | 1〜30秒 |
| `movingShredderSpeed` | 1マス/秒 | 0.25〜3マス/秒 |
| `freezerSeconds` | 3秒 | 0.5〜10秒 |
| `frozenSpeedMultiplier` | 0.35倍 | 0.1〜0.9倍 |

クッキーの最後の一撃は滑走を止めずに通します。破壊後は初期設定で20秒間復活せず、その後に耐久を全回復します。クッキー・スコーンとも、復帰先をフルーツ・移動刃が占有していれば空くまで待ち、よだれは復帰時に消去します。フリーザーは踏み直すと残り時間を更新し、速度倍率は重複しません。移動刃は壁・ゼリー・壊れていないスコーンやクッキー・固定刃・別の移動刃・パイプ・盤外を避けて反転します。歩行中のフルーツがいる進路も避け、両側がふさがれば待機します。収穫には滑走状態が必要です。

スコーンには斜面側から歩行・滑走とも進入でき、マスの中心に乗ってから90度転向します。この転向では壁で曲がる左右の順番を進めません。斜めではない2つの側面は壁として扱い、歩行では右・左の交互転向、滑走ではマスの手前で衝突して停止します。歩行では耐久を削りません。滑走衝突は斜面・側面とも耐久を1回分削り、20回目で破壊して直進します。破壊後は歩行・滑走・よだれ配置が可能な床になり、初期設定で5秒後に耐久20回まで回復して復帰します。耐久は全ステージ共通で滑走20回です。Unity上ではスコーンのY回転を0/90/180/270度、移動シュレッダーのY回転を0/180度（横）または90/270度（縦）に設定できます。実行時は実際のシーン上の位置と向きを使います。

全フルーツの歩行は、壁や障害物に当たるたびに進行方向を基準として右・左と交互に曲がります。最初は右折です。予定の側がふさがっていれば反対側へ、両側ともふさがっていれば後退し、どこにも進めなければ待機します。

歩行中のオレンジは、クッキーへの1回の接触で耐久を1削ります。壊せなければ短い反動の後に同じ交互転向を行い、その衝突で壊せたら直進して通り抜けます。破壊時は左右の順番を進めません。滑走中は全フルーツ共通で、最後の一撃で壊してそのまま通り抜けます。

各パイプから下方向へ出て、固定壁・ゼリー・パイプを避けながら、固定/移動シュレッダーの初期位置と盤外に到達できることを検証します。パイプ自体を出口への経路には数えません。壊れるクッキーとスコーンは開通可能として扱います。この検証は接続性の確認であり、反射角や移動刃のタイミングまで考慮したクリア可能性を保証するソルバーではありません。

同梱の導入ステージは16×9、固定刃4＋横移動刃1。2番目は20×12、固定刃6＋横移動刃1＋縦移動刃1です。1マスに保存できる配置物は1種類です。よだれはプレイ中に置くためJSONには保存しません。

配置とゲームルールのみを保存します。モデルやマテリアルの選択はJSONに持たせず、UnityのGameAssetsとPrefabで変更します。
