# ステージJSON v1

座標は左上が `(0,0)`。Xは右方向、Yは下方向に増えます。Unityの座標ではXZ平面を使い、上の行ほどZが大きくなります。

```json
{
  "version": 1,
  "name": "はじめてのキッチン",
  "dessert": "フルーツタルト",
  "width": 16,
  "height": 9,
  "rows": ["各行に幅と同じ個数のASCII記号を記述"],
  "recipe": {"strawberry": 5, "blueberry": 4, "orange": 3, "melon": 1},
  "escapeLimit": 10,
  "spawnInterval": 3.6,
  "iceLifetime": 5,
  "droolLifetime": 10
}
```

上記のrowsは説明用です。読み込み可能な完全な例は `Assets/BetoBeto/Stages/kitchen-01.json` と `kitchen-02.json` にあります。

| 記号 | 内容 | 制約 |
| --- | --- | --- |
| `.` | 床 | 制約なし |
| `#` | クッキーの壁 | プレイヤーは通過できる |
| `P` | 生成パイプ | 最上段、2〜3基 |
| `X` | シュレッダー | 4〜8箇所 |
| `E` | 出口 | 外周のみ |
| `G` | プレイヤー開始位置 | 必ず1箇所。ゲーム上は床 |

幅16〜32・高さ9〜18、各行の長さはwidth、行数はheightと一致させます。各フルーツ数は0以上の整数で、合計1〜200。脱出上限は1〜99。出現間隔0.5〜30秒、氷の寿命1〜30秒、よだれ1〜60秒。

各パイプから壁を避けてシュレッダーと出口に到達できることを検証します。この検証は接続性の確認であり、プレイヤー操作込みでのクリア可能性を保証するソルバーではありません。外周の床を開けた場合は、盤面外への移動も脱出になります。

配置とゲームルールのみを保存します。モデルやマテリアルの選択はJSONに持たせず、UnityのGameAssetsとPrefabで変更します。
