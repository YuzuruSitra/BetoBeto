# 同梱フォント

`Assets/BetoBeto/Resources/Fonts/MPLUSRounded1c-Regular.ttf` は [Google Fonts の M PLUS Rounded 1c](https://github.com/google/fonts/tree/main/ofl/mplusrounded1c) の Regular を変更せずに同梱しています。

- Copyright 2016 The Rounded M+ Project Authors.
- SIL Open Font License 1.1。著作権とライセンスの指定はフォント内の name テーブルでも確認済み。
- ライセンス全文：`Assets/StreamingAssets/ThirdParty/MPLUSRounded1c-OFL.txt`。WebGL出力にも含まれ、ページ下部から閲覧できます。
- 日本語はOSのインストール済みフォントに依存せず、UnityのDynamic Fontとして使用します。

ライセンス本文は [M+ FONTS upstream の OFL.txt](https://github.com/coz-m/MPLUS_FONTS/blob/master/OFL.txt) と同じ SIL OFL 1.1 です。冒頭の著作権表示には、配布している Rounded M+ フォント自身の表示を使用しています。
